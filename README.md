# dragndrop-puzzle
A simple drag-and-drop puzzle made in HTML and Javascript.

Originally written quickly in an evening as part of a technical skills test during an interview process. Since then, it's sat in my repository collection gathering dust until I decided to take another pass at it. The original will be kept as `v1.html`, and any associated css, javascript, and assets will be labelled accordingly.

## Directions
Open index.html in the web browser of your choice. Depending on the browser security settings, you may have to run a local webservice, or you can visit the online version at (https://puzzle.reubenbradley.website).
